4. Automated backups run on schedule "{{ .Values.backup.schedule }}". Run one now:

WARNING: This is a single-pod Omnibus deployment. It is vertically scalable and
resilient to node failure (data on PVCs, pod reschedules), but it is NOT
horizontally highly-available. For zero-downtime HA, externalize Postgres/Redis/
object storage and migrate to the GitLab Operator or cloud-native chart — see
docs/deployment-approaches-tradeoffs.md.
