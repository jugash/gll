NOTE: Datastores use license-clean images (CloudNativePG / Valkey / MinIO), not
Bitnami. Defaults are single-instance (reliable, simple). For production HA set
postgresql.instances=3 and deploy HA Valkey via a Redis/Valkey operator, then set
redis.sentinel.enabled=true. See docs/installation-guide.md.

PREREQUISITE: the CloudNativePG operator must be installed (OperatorHub) before
this chart, since PostgreSQL is a CNPG Cluster resource.
